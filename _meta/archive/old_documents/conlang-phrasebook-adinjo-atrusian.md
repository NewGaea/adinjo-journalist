# **Greetings** {#greetings}

| English         | Conlang                  |
| :-------------- | :----------------------- |
| Hello, I'm ...  | *Hayl, yi’ch \[Name\].*  |
| I come from ... | *Yi’ch \[Place\]’hemle.* |
| I live in ...   | *Yi jenais ni ...*       |
| America         | *Amerika*                |
| France          | *Frans*                  |
| Germany         | *Doichland*              |
| Euskal Herria   | *Yuskal Herria*          |
| Goodbye         | *Feis.*                  |

No matter what the time of day, in Adinjo the word for “hello” is *Hail* and the word for goodbye is *Feis*. However, time-based greetings do exist as well:

| English | Conlang |
| :---- | :---- |
| Good ... | *Sayomin...* (greeting) *Sayu...* (departing) |
|     morning |     *krestu* |
|     day, afternoon |     *kolbu* |
|     evening |     *jurabi* |
|     night |     *cochi* |

## ***Names in Conlang*** {#names-in-conlang}

Names in Adinjo are written in all UPPPERCASE. Nicknames, pet names, and other affectionate terms may be written with only the first letter Capitalized. When importing a name into Adinjo, the rules are to use the closest phonetic representation Adinjo allows.

Native Conlang names are often formed by joining parts of words spoken in past generations, or from old phrases or utterances:

| Name | Word Parts |
| :---- | :---- |
| *Jenesis* | life+(quality): lively |
| *Ireon* | “I came first” (from primitive Yreons) |
| *Menha* | name+without |
| *Doichi’ijmo* | German+country |

| English | Conlang |
| :---- | :---- |
| I am (a) … | *Yi’ch...* |
|      Spanish |  ISPANYA |
|      Hispanic |  ISPANYAMERIKA |
|      French |  IFRANS |
|      Chilean |  ICHILE |
|      Czech |  ICHEK |
|      Breton |  IBRETON |
|      Hungarian |  IHUNGARI |
|      Basque |  IBASKE |
|      Russian |  IRUSHA |

# **Money** {#money}

The unit of money in international Atrusian Trade, regardless of language, is the gilden, split into 144 deimo, each split into 12 kang (the kang may be further split into twelve tendy, but this is not common in international trade). The exchange rate as of 17 November 2014 is currently 4.80076814 kang (slightly under 4 kang 10 tendy) to the American dollar. In Adin, the coins are called by how many units they represent, prefixed to a variant form of their name.

The coins are:

| Monetary Unit | Equivalent Value |
| :---- | :---- |
| kang | 0.2083 USD |
| jokkan | 0.625 USD |
| lukkan | 1.25 USD |
| deimo | 2.50 USD |
| jodeim | 7.50 USD |
| ludeim | 15.00 USD |
| modeim | 30.00 USD |
| lummodeim | 180.00 USD |
| gilden | 360.00 USD |
| jogild | 1080.00 USD |
| lugild | 2160.00 USD |

## ***Asking for things / marketing*** {#asking-for-things-/-marketing}

Unlike many other languages, it is not necessary in Conlang to turn orders into polite questions ; politeness words are completely optional, and it is not rude to omit them.

# **Numbers** {#numbers}

In general, numbers in Conlang are expressed by reading off the digits from left to right, with a few exceptions. There are special words for some powers of ten, which aren't always used.  
In some parts of Conlangland, an entirely different system based on hexadecimal is used, though as a foreigner your numbers will probably be understood if you say them in decimal.
